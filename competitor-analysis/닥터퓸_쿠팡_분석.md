> **가장 큰 약점:** **광고·유튜브 기대 대비 소취 효과 미달 + 향 지속 의문 + 가격 가성비 논란** — 효능을 입증할 수치·임상이 0이라 "효과 없다/광고만 못하다" 저별점을 방어하지 못함. 또 **올인원(샴푸겸용)은 오히려 불만 지점.**

### 💡 ORDO 시사점 (참고)
- 닥터퓸의 최대 빈틈 = **'효능 근거 부재'.** ORDO가 **소취 데이터(수치·시험) + 좋은 향**을 동시에 제시하면 "광고만 못하다"는 저별점 층을 흡수 가능.
- **'아버지·남편 선물' 수요가 채널 불문 강력**(스토어·쿠팡 공통) → '선물 안심(민감어 미표기) + 효심 메시지' 패키지가 먹힘.
- **올인원(샴푸겸용) 소구는 역효과** 가능 → ORDO는 '바디 전용 소취'로 명확히 포지셔닝하는 편이 신뢰에 유리(추정).

## 데이터 신뢰도 메모 (원본 대조 필요 수치)
- **리뷰 비율 %(만족/불만):** **텍스트 54건 기준**(수집 358건 중 무텍스트 다수). 절대 표본이 작아 *방향성 지표*. 정밀 수치는 전체 1,096건 대조 필요.
- **별점 분포(5★ 74%):** 수집 358건 기준. **장문·광고형 5★ 리뷰 다수 관찰**(체험단/협찬 가능성) → 5★ 비중에 인센티브 리뷰 영향 가능성(추정), 저별점이 더 솔직한 신호.
- **평점 4.5 / 1,096건:** 웹 표기값(수집 시점 기준). 쿠팡 화면 평점과 재대조 권장.
- **가격(단품 ₩30,000대):** 쿠팡 화면가 직접 미수집 → 웹 교차 기반 **추정**. 실제 쿠팡가 재확인 필요.
- **성분 함량/특허/실험수치:** 상세페이지에 **수치 자체가 없음**(정성 표현만) → '근거 부재'는 사실, 단 미공개 데이터 존재 여부는 별도 확인 필요.
- **빈틈 포화:** 저별점 텍스트 8건에서 유형 수렴했으나 표본 작음 → 전체 저별점(약 49건+) 텍스트 추가 수집 시 재검증 권장.
